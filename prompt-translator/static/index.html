Ako to funguje:
1. Váš prompt sa komprimuje (Claude Haiku) – kratší vstup pre hlavný model
2. Hlavný model dostane inštrukciu odpovedať telegraficky
3. Komprimovaná odpoveď sa expanduje späť do prirodzeného jazyka
